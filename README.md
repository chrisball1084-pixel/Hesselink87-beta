# Hesselink87 Beta

Aktiv weiterentwickelte Trainings-App/PWA der Hesselink87-Reihe.

## Projektworkflow

Dieses Repository verwendet den gemeinsamen Skywalker App Development Standard:

- `docs/PROJECT.md` — zentrale technische Projektdokumentation
- `AGENTS.md` — Arbeitsregeln für Codex
- `CLAUDE.md` — Arbeitsregeln für Claude Code
- `CHANGELOG.md` — historische technische Änderungen
- Notion `Hesselink87 App updates` — Product Hub für Feedback, offene Punkte, Entscheidungen und aktuellen Produktstatus

Standardbefehl für Agent-Arbeit:

`Notion Sync durchführen`

## Deployment

Die App wird als statische PWA über GitHub Pages ausgeliefert. Vor Releases aktuelle Versions-/Cache-Mechanismen im Code und Service Worker prüfen; keine Versionsnummer aus Dokumentation übernehmen.

## Legacy-Hinweis

Das separate Repository `Hesselink87` ist eine ältere, deutlich schlankere Codebasis. Neue Entwicklung findet in diesem Beta-Repository statt, solange keine explizite Produktentscheidung das ändert.
